## Captured states

The source manager reads the full article. Images show adding, listing, filtering, reviewing, editing, and reusing its citations. The filled reference-details draft is a demonstration input and has not been published.

MediaWiki page configuration, ResourceLoader, and API responses are local fixtures. Network access and live writes are blocked.
